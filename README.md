# car-parking-manegement-system-using-linked-listCar Parking Management System Using Linked List

1. Introduction

This project manages parked cars using a linked list in C++.

2. Problem Statement

Manual parking management is time-consuming and difficult. This system helps manage vehicle records efficiently.

3. Objectives

- To manage car parking records.
- To understand linked lists.
- To add and remove cars.
- To search and display car details.
- To check parking availability.

4. Data Structure Used

Linked List is used to store vehicle details dynamically.

5. Technologies Used

- Language: C++
- Concept: Linked List
- Platform: C++ Compiler

6. Features

- Add a car.
- Display parked cars.
- Search for a car.
- Remove a car.
- Check parking availability.

7. Algorithm

1. Start the program.
2. Initialize an empty linked list.
3. Display the menu.
4. Accept the user's choice.
5. Perform the selected operation.
6. Repeat until Exit is selected.
7. Stop the program.

8. Working Principle

Each car is stored in a linked-list node. Nodes are added, searched, displayed, or deleted as required.

9. Advantages

- Easy to use.
- Saves time.
- Supports dynamic memory allocation.
- Makes car records easy to manage.

10. Applications

- College parking.
- Office parking.
- Shopping malls.
- Residential parking.

11. Limitations

- Records may be lost after program termination.
- Requires manual data entry.

12. Future Scope

- Database connectivity.
- Automatic fee calculation.
- Entry and exit time tracking.
- Online payment system.

13. Conclusion

This project demonstrates the use of linked lists for efficient car parking management using C++.

14. Expected Output

The system displays a menu to add, display, search, and remove cars and check parking availability.

- Project: Car Parking Management System Using Linked List
- Language: C++
- Subject: Data Structures
